About

ما هو TypoMaster؟

تطوير مهارات الطباعة لديك من الصفر إلى الاحتراف مع أفضل برنامج تدريب مجاني

🎯

لماذا TypoMaster؟

TypoMaster ليس مجرد برنامج طباعة عادي. إنه منصة متكاملة تجمع بين الدروس النظرية، التمارين العملية، والألعاب التفاعلية لتجربة تعلم ممتعة وفعالة. يدعم العربية والإنجليزية بشكل متكامل.

💡

الفكرة الأساسية

التعلم عن طريق الممارسة المستمرة مع متابعة دقيقة للأداء. كل درس يبني على الذي قبله، وكل تمرين يصقل مهاراتك. الألعاب تجعل التعلم ممتعاً والإحصائيات تساعدك على رؤية تقدمك.

🆓

مجاني تماماً

التطبيق مفتوح المصدر بالكامل (MIT License). لا إعلانات، لا اشتراكات، لا بيانات مخفية. حمّله واستخدمه مجاناً للأبد.

🚀

أداء عالٍ

مبني باستخدام Tauri + Rust لتطبيق سطح مكتب خفيف وسريع. استهلاك منخفض للموارد، وقت تشغيل فوري، وحجم تحميل صغير (~28 MB).

FAQ

الأسئلة الشائعة

ما هو TypoMaster بالضبط؟ +
TypoMaster هو برنامج تدريب طباعة احترافي مجاني ومفتوح المصدر. يدعم العربية والإنجليزية، ويوفر 210+ تمرين، 40 درس نظري، 5 ألعاب تفاعلية، وتحليلات أداء متقدمة. مبني باستخدام React + Tauri + Rust.
كيف أحمل التطبيق؟ +
اذهب إلى صفحة Releases على GitHub، اختر "TypoMaster_1.0.0_x64_en-US.msi" للنسخة المثبتة أو "TypoMaster_x64_portable.zip" للنسخة المحمولة. فك الضغط وشغّل.
هل التطبيق متوفر لأنظمة أخرى؟ +
حالياً Windows 10/11 فقط (64-bit). دعم macOS و Linux قادم في الإصدار 1.1. يمكنك بناء التطبيق من المصدر لأي نظام يدعمه Tauri.
هل أحتاج اتصال إنترنت لاستخدامه؟ +
لا. TypoMaster يعمل بشكل كامل بدون إنترنت. كل المحتوى، النصائح الذكية، وقاعدة البيانات مدمجة في التطبيق. الإنترنت مطلوب فقط للتحميل الأولي.
هل البرنامج مجاني حقاً؟ +
نعم، TypoMaster مجاني تماماً ومفتوح المصدر تحت رخصة MIT. لا إعلانات، لا اشتراكات، لا بيانات مخفية. يمكنك استخدامه وتعديله وتوزيعه بحرية.
كيف أعيد تعيين كل البيانات؟ +
الإعدادات ← متقدم ← إعادة تعيين كل البيانات. أو احذف يدوياً ملف: %APPDATA%/com.typomaster.desktop/TypoMaster.db
ما هي متطلبات النظام؟ +
Windows 10/11 64-bit، WebView2 Runtime (مضمن في Windows 11)، ~50 MB مساحة تخزين، 4 GB RAM موصى بها.
كيف يمكنني المساهمة في المشروع؟ +
Fork المشروع على GitHub، نفذ التغييرات، تأكد من npm run lint بدون أخطاء، ثم أرسل Pull Request. راجع CONTRIBUTING guidelines في README.
