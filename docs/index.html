FAQ

الأسئلة الشائعة

كيف أحمل التطبيق؟ +
اذهب إلى صفحة Releases على GitHub، حمّل TypoMaster_1.0.0_x64_en-US.msi، ثم شغّله. سهل وسريع.
هل التطبيق متوفر لأنظمة أخرى؟ +
حالياً Windows فقط. دعم macOS و Linux قادم في الإصدار 1.1. يمكنك بناء التطبيق من المصدر لأي نظام.
هل أحتاج اتصال إنترنت لاستخدامه؟ +
لا. TypoMaster يعمل بشكل كامل بدون إنترنت. النصائح الذكية مدمجة في التطبيق. الإنترنت مطلوب فقط للتحميل الأولي.
كيف أعيد تعيين كل البيانات؟ +
الإعدادات ← متقدم ← إعادة تعيين كل البيانات، أو احذف ملف قاعدة البيانات من %APPDATA%/com.typomaster.desktop/TypoMaster.db.
الموسيقى لا تعمل؟ +
تأكد من وجود ملفات public/music/track-1.mp3 إلى track-10.mp3. إذا كانت مفقودة، أعد بناء التطبيق أو حمّل الموسيقى من GitHub.
